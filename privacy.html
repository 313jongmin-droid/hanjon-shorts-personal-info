개인정보처리방침

적용일: 2026-10-25. 이 방침은 채널 소유자 한 명이 사용하는 개인용 앱의 현재 데이터 처리 방식을 설명합니다.

접근하는 데이터와 목적

사용자 동의로 YouTube 채널 ID·채널명·영상 목록과, 조회수·시청 시간·시청 지속·참여 조회수·공유·구독 증가 등 소유 채널의 Analytics를 읽습니다. 대상 채널 확인과 개인적인 콘텐츠 성과 검토에 사용합니다. 업로드·수정·삭제 권한은 요청하지 않습니다.

저장과 보안

OAuth 클라이언트 자격과 토큰은 소유자의 Windows 사용자 계정에 연결된 암호화 방식으로 로컬 보관합니다. 조회 결과와 비밀값을 제외한 요청·오류 기록은 해당 컴퓨터의 별도 앱 폴더에 저장하며, 결과 파일 자체는 암호화하지 않습니다. 컴퓨터 계정 및 백업 접근을 소유자가 관리해야 합니다.

전송과 공유

인증과 조회에 필요한 요청만 Google OAuth 및 YouTube API 서버로 보냅니다. 이 버전은 조회 데이터나 인증값을 GitHub Pages, 광고업체 또는 외부 AI 서비스로 보내지 않습니다. 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다. 이 앱의 Google API 데이터 사용 및 전송은 Google API Services User Data Policy와 Limited Use 요구사항을 따릅니다.

권한 철회와 데이터 삭제

소유자는 Google 계정의 연결 관리에서 앱 권한을 철회할 수 있습니다. 철회는 컴퓨터에 이미 저장한 파일을 자동 삭제하지 않습니다. 저장 데이터는 별도 앱 폴더의 data 및 evidence에서, 인증은 .private에서 소유자가 삭제할 수 있습니다. 앱 중지·권한 철회·로컬 데이터 삭제는 서로 다른 작업입니다. 다른 앱의 인증이나 자막 결과는 삭제 대상이 아닙니다.

안내 사이트

이 정적 사이트에는 로그인 양식·분석 스크립트·추적용 쿠키를 넣지 않습니다. 호스팅 제공자인 GitHub가 접속에 필요한 기술 정보를 처리할 수 있으며 GitHub 개인정보처리방침이 적용됩니다. 앱 데이터는 이 사이트에 저장하지 않습니다.

문의와 변경

문의는 사이트 저장소 이슈를 이용할 수 있습니다. 토큰·비밀번호·비공개 성과는 공개 이슈에 올리지 마세요. 처리 방식이 바뀌면 이 방침을 먼저 갱신합니다.
