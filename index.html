한존커플 채널 소유자가 자신의 영상 목록과 YouTube Analytics를 확인하는 개인용 데스크톱 도구입니다.

앱이 하는 일

Google 사용자 OAuth 동의를 받은 뒤, 연결된 채널이 한존커플인지 확인하고 영상 목록·일별 성과·선택한 롱폼의 시청 지속·쇼츠 시청 지표를 조회합니다. 결과는 소유자의 Windows 컴퓨터에 저장합니다.

요청하는 권한

  • YouTube 계정 보기: 채널과 영상 목록 확인
  • YouTube 분석 보고서 조회: 소유 채널의 비공개 성과 확인

이 도구는 읽기 권한만 요청합니다. 영상 편집·업로드·삭제, 댓글 작성, 자막 수정 기능은 제공하지 않습니다. Google 또는 YouTube가 제공하거나 인증한 공식 앱이 아닙니다.

이 웹사이트

이 사이트는 앱 안내와 데이터 처리 방침을 공개하는 정적 페이지입니다. 여기서 로그인하거나 채널 데이터를 제출하지 않습니다. 실제 Google 동의는 Google의 인증 페이지에서 진행됩니다.
